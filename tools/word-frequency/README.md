# 頻出単語の分析ツール

過去問のテキストから英単語の出現回数を数えて、「何年分の試験に出てきたか」「合計で何回出てきたか」をCSVに出力します。

## 1. 紙の過去問をテキストにする（OCR）

いちばん手軽なのは **Googleドライブ** を使う方法です（無料）。

1. 過去問をスマホで撮影するか、スキャナーでPDFにする
   - ページをまっすぐ、影が入らないように撮ると、読み取りの精度が上がります
2. 画像またはPDFをGoogleドライブにアップロードする
3. ファイルを右クリック →「アプリで開く」→「Googleドキュメント」
4. 文字に変換された文章が表示されるので、英文の部分だけをコピーする
5. メモ帳などに貼り付けて、**文字コードUTF-8** で保存する

ほかに、iPhoneの「テキスト認識表示」やGoogleレンズでも文字を取り出せます。

### 保存のルール
- `data` フォルダを作り、**1年分を1ファイル**にする（例: `data/2024.txt`）
- 英文だけを残し、日本語の設問文はできるだけ消す
- 読み取りミス（`l` と `1`、`rn` と `m` など）は、気づいた範囲で直す。全部直さなくても、頻出単語のランキングにはほとんど影響しません

> ⚠️ 過去問の英文は著作物なので、`data` フォルダはGitHubにアップロードされないように設定してあります（`.gitignore`）。アプリにも英文そのものは載せないでください。

## 2. 実行する

Java 17以降が必要です。このフォルダ（`tools/word-frequency`）で次を実行します。

```
java src/WordFrequency.java data output/nagoya.csv
```

コンパイル（`javac`）は不要で、このコマンドだけで動きます。まず動作を試したい場合は、サンプル文（自作の英文）を使えます。

```
java src/WordFrequency.java samples output/sample.csv
```

## 3. 結果の見方

`output/nagoya.csv` をExcelやGoogleスプレッドシートで開きます。

| 列 | 意味 |
|---|---|
| 単語 | まとめた後の単語（例: studies, studied → study） |
| 合計回数 | 全部の年で出てきた回数の合計 |
| 出てきた年数 | 何年分のファイルに出てきたか。**多いほど毎年出る大事な単語** |
| まとめた形 | どの形をまとめたか。まとめ方が間違っていないかの確認用 |

並び順は「出てきた年数が多い順 → 合計回数が多い順」です。

## 4. 調整のしかた

`src/WordFrequency.java` の中の2つのリストを書きかえると、結果を調整できます。

- `STOP_WORDS`：数えない単語（基本的な単語）。ランキングに不要な単語が多ければ追加する
- `NO_MERGE`：まとめてはいけない単語。`news` → `new` のように意味が変わってしまう単語を追加する

## 今の仕組みでできないこと

- `went` → `go` のような不規則変化はまとめられません
- `take part in` のようなイディオム（熟語）は数えられません（今後の改善点）
- 単語がどの意味で使われているかの判定はできません（AIの下書き＋自分で確認する予定）
