# 実機確認の手順（12月：自分のドメインに移したあと）

ログイン機能を出したあと、本物の端末で一度だけ通して確かめる手順です。全部で30〜40分ほどです。
用意するもの：iPhone（Safari）、Android（Chrome）、パソコン（Chrome か Edge）。持っていない端末は飛ばしてかまいません。認証アプリ（Google Authenticator など）を入れたスマホを1台。

結果は「○ / × / 気になったこと」を Claude に伝えてください。

## A. 登録とログインしない使い方（iPhone）
1. アプリのアドレスを Safari で開く。ログインせずに、演習を5問ほど解く
2. 「アカウント」タブで、ニックネーム（例：テスト1）を入れて「パスキーで登録」
   - 確認：Face ID か Touch ID の画面が出て、登録できる
   - 確認：復旧コード（XXXX-XXXX-… の形）が表示される → 紙かメモに写す
3. 「記録を今すぐ保存」を押す → 保存できたという知らせが出る

## B. 2段階認証（iPhone ＋ 認証アプリ）
1. 「認証アプリを設定する」→ QR コードを認証アプリで読む
2. 認証アプリの6桁を入れて「有効にする」→ 「有効です」と出る
3. わざと違う6桁を入れたときに「コードが違います」と出ることも確かめる

## C. 別の端末で引き継ぐ（Android）
1. アプリのアドレスを Chrome で開く。「アカウント」タブ → 「スマホを替えた・パスキーが使えないとき」を開く
2. A で写した復旧コードと、認証アプリの6桁を入れてログイン
   - 確認：A で解いた記録（記録タブの数字、ブックマークなど）が出ている
   - 確認：新しい復旧コードが出る（前のコードはもう使えない） → 写す
3. 「この端末のパスキーを追加」→ 指紋か画面ロックで登録できる
4. いったんログアウトし、「パスキーでログイン」→ 6桁 → ログインできる

## D. パソコン
1. Chrome か Edge で開き、「パスキーでログイン」を押す
2. 表示された QR コードを iPhone のカメラで読み、iPhone のパスキーでログインできるか確かめる（スマホのパスキーをパソコンで使う方法）

## E. 後片づけ
1. iPhone で「そのほか」→ ニックネームと6桁を入れて「アカウントを消す」
2. 各端末の設定から、テスト用のパスキー（サイト名：入試 英単語 ナイン）を消す
   - iPhone：設定 → パスワード
   - Android：Google パスワード マネージャー
3. Claude に「実機確認が終わった」と伝える（サーバーに残ったテスト用の記録を消します）

## うまくいかないとき
- パスキーの画面が出ない：iOS 16 以上・Android 9 以上か、画面ロックが設定されているかを確かめる
- 「このページからは使えません」：アドレスが公開ドメインと違う（ORIGINS の設定もれ）→ Claude に伝える
- それ以外：画面のスクリーンショットを撮って Claude に送る
