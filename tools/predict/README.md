# 予想記事の自動ピックアップ

名大のアドミッション・ポリシー（令和9年度 選抜要項）と、旧帝大の過去の出典の傾向をもとに、入試に出そうな英文記事を集め、アプリにまだ入っていない単語を洗い出します。

- `profile.json`：記事の選び方の基準（テーマと重み、除外する話題、読みにいく媒体、記事の長さ）
- `pick_articles.py`：記事を集めて点数をつけ、上位の記事から単語を洗い出す
- `picked_urls.txt`：これまでに選んだ記事のURL（同じ記事を二度選ばないため）

```
python3 tools/predict/pick_articles.py 出力フォルダ
```

出力フォルダには、記事の本文・選んだ記事の一覧（articles.csv）・新しい単語（new_words.csv）ができます。記事の本文は著作物なので、このリポジトリには入れないでください。

## 基準の根拠（名大のアドミッション・ポリシーより）
- 大学全体：未来の「勇気ある知識人」。基礎的な学力と、それを活用する力・発展させる意欲
- 理学部：理学の幅広い教養、知的好奇心。個別試験の外国語で「読解力・表現力・論理的思考力」を測る
- 工学部：自然科学への強い興味と、人間や社会への幅広い関心。現代社会の問題への挑戦
- 医学部保健学科：生命への畏敬、科学的探究心、多様な価値観を受け入れる寛容さ
- 農学部：「食・環境・健康」に関わる学問
