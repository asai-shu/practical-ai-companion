# プライバシーポリシー（案）

> 有料版を始めるときは、支払いの項目を見直します。

「入試 英単語 ナイン」（以下「本アプリ」）の運営者（以下「運営者」）は、利用者の情報を次のとおり取り扱います。本アプリは中学生・高校生を含む未成年の方が使うことを前提に、集める情報をできるだけ少なくしています。

## 1. 集める情報

| 情報 | 集めるとき | 保存する場所 |
|---|---|---|
| 学習の記録（解いた問題、覚えた度合い、単語帳、ブックマーク、設定） | 本アプリを使うとき | 利用者の端末の中だけ |
| ニックネーム | アカウントを作るとき（任意） | 運営者のサーバー |
| パスキーの公開鍵 | アカウントを作るとき・端末を追加するとき | 運営者のサーバー |
| 学習の記録の写し | アカウントを作った人が記録を同期するとき | 運営者のサーバー |
| 2段階認証の設定（暗号化した秘密の値） | 2段階認証を有効にしたとき（任意） | 運営者のサーバー |
| 接続元の IP アドレス | ログインに関する操作のとき（試行回数の制限のため。1日で消します） | 運営者のサーバー |

次の情報は集めません：氏名、メールアドレス、電話番号、住所、学校名、生年月日、パスワード、指紋や顔の情報（パスキーの指紋・顔認証は端末の中だけで行われ、運営者には届きません）。

アカウントを作らなければ、学習の記録が端末の外に送られることはありません。

## 2. 使い道
- 学習の記録を、複数の端末で引き継げるようにするため
- 本人確認（ログイン）と、不正なログインを防ぐため
- 本アプリの不具合を直し、改善するため（個人を特定しない形で集計する場合に限ります）

広告のためには使いません。

## 3. 第三者に渡すこと
法令にもとづく場合を除き、利用者の情報を第三者に渡しません。
ただし、本アプリは次のサービスを使って動いています。これらのサービスは、運営者の指示の範囲でのみ情報を扱います。
- Supabase（データベースとサーバーの処理。東京の拠点を使用）
- Cloudflare（Webサイトの配信）

## 4. 安全のための取り組み
- ログインにパスワードを使わず、パスキーを使います
- ログインの記録や復旧コードは、元に戻せない形（ハッシュ）でだけ保存します
- 2段階認証の秘密の値は暗号化して保存します
- 通信はすべて暗号化（HTTPS）しています

## 5. 情報の削除
アカウントの画面の「アカウントを消す」から、いつでも自分で消せます。消すと、ニックネーム、パスキー、サーバーにある学習の記録は、すぐにすべて消えます。端末の中の記録は、ブラウザのサイトデータを消すと消えます。

## 6. 保護者の方へ
未成年の方が使う場合は、保護者の方の了解のうえで使ってください。お子さまの情報を消したいときは、下の連絡先までご連絡ください。

## 7. 変更
内容を変えるときは、本アプリの中でお知らせします。
